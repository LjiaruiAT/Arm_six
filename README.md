## 1. 规划中的结构

```
src/
├── arm              URDF / 参数 / 机器人描述

├── arm_interfaces   自定义 msg / srv
```

## 3. 为什么单独建仓

六轴机械臂与底盘/六足的技术栈不同：它面对的是**多解筛选、奇异位形、关节限位**与末端位姿精度，本质上是另一条学习曲线。单独开仓是为了把这条线独立推进，不污染已有项目。
